# 💰 Rynance — Controle Financeiro

O **Rynance** é um sistema de controle financeiro desenvolvido para auxiliar no gerenciamento e organização das finanças pessoais.

A aplicação permite acompanhar as movimentações financeiras de forma simples e organizada, proporcionando uma visão mais clara sobre receitas, despesas e saldo.

🌐 **Acesse o sistema:** [Rynance](https://rynance.netlify.app)

---

## 📋 Sobre o projeto

O Rynance foi desenvolvido como uma aplicação web com foco em **controle financeiro pessoal**, buscando oferecer uma interface simples, intuitiva e responsiva.

O projeto também tem como objetivo aplicar na prática conceitos de desenvolvimento web, organização de código, componentes reutilizáveis, gerenciamento de estado e desenvolvimento de interfaces com React.

---

## 🚀 Funcionalidades

* 💰 Gerenciamento de receitas
* 💸 Gerenciamento de despesas
* 📊 Visualização das informações financeiras
* 🧮 Controle do saldo

* 📱 Interface responsiva
* 📈 Visualização dos dados financeiros

## 📦 Como executar o projeto localmente

### Pré-requisitos

Para executar o projeto localmente, é necessário ter instalado:

* [Node.js](https://nodejs.org/)
* npm
* Git

### 1. Clone o repositório

```bash
git clone https://github.com/RyNicolau/rynance_controle_financeiro.git
```

### 2. Acesse a pasta do projeto

```bash
cd rynance_controle_financeiro
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Depois disso, o Vite iniciará o servidor de desenvolvimento e informará no terminal o endereço para acessar a aplicação.

Normalmente:

```text
http://localhost:5173
```

---

## 🏗️ Build para produção

Para gerar a versão otimizada para produção:

```bash
npm run build
```

Os arquivos finais da aplicação serão gerados na pasta:

```text
dist/
```

Para visualizar localmente a versão de produção:

```bash
npm run preview
```
